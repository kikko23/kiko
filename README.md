# Projet Kiko - Streaming Local avec OBS Studio

## Description
Ce projet contient toutes les ressources nécessaires pour configurer et utiliser OBS Studio pour du streaming local.

## Structure du projet
```
kiko/
├── docs/               # Documentation complète
├── configs/            # Configurations OBS prédéfinies
├── scripts/            # Scripts d'automatisation
└── scenes/             # Scènes OBS exportées
```

## Démarrage rapide
1. Consultez `docs/OBS_GUIDE.md` pour la documentation complète
2. Utilisez les configurations dans `configs/` pour démarrer rapidement
3. Importez les scènes depuis `scenes/` dans OBS Studio

## Prérequis
- OBS Studio (version 28.0 ou supérieure recommandée)
- Système: Windows/macOS/Linux
- Pour le streaming local: serveur RTMP ou Nginx avec module RTMP
